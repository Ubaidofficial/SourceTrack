# SourceTrack Marketing Site

Standalone Astro v6 marketing site for SourceTrack. Built for high performance, zero-JS static SSG, and fast TTFB on Cloudflare Pages or Railway.

## 🚀 Quick Start

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build production static bundle
npm run build
```

## 🛠️ Architecture

- **Framework**: Astro 6.x + React islands
- **Styling**: Tailwind CSS v4
- **SEO & Schemas**: `@astrojs/sitemap`, JSON-LD (`Organization`, `SoftwareApplication`, `FAQPage`, `BreadcrumbList`, `Article`)
- **Canonicals**: Default host `https://www.sourcetrack.ai`
