Install the SourceTrack snippet on your Shopify store via the theme liquid editor or Google Tag
Manager, and stitch cart attributes to order completions. Order revenue arrives through a **manual
webhook recipe**: you add the webhook in your own Shopify admin and paste the signing secret into
SourceTrack's Integrations page. There is no Shopify App Store listing and no app to install.

**Test-mode beta.** No production store is connected to this path yet, so it is proven by our own
test suite rather than by live revenue. If you need this part battle-tested, wait.
